🧱 Restaurant-Page - Webpack + JavaScript

Exercício prático de Webpack e manipulação do DOM, proposto pelo currículo do The Odin Project.

O objetivo deste repositório é simples: praticar o uso do Webpack criando uma página de restaurante construída inteiramente com JavaScript. Todos os elementos (títulos, textos, imagens e menus) são criados, estilizados e inseridos no DOM via JS, sem escrever o conteúdo diretamente no HTML. Não é uma aplicação completa, não está pronto para produção e não é responsivo.
